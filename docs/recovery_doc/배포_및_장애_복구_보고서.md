# 배포 및 장애 복구 보고서

> **작성 기준:** 「장애복구_시스템_구현_기획서」 기준의 계획 보고서. 실제 배포 및 장애 복구 시험은 아직 진행되지 않아 실적값은 기재하지 않았다.

## 1. 배포 현황

| 항목 | 현황 |
|---|---|
| 배포 일자 / 버전 / 환경 | ________ / ________ / ________ |
| 멀티 컨테이너 배포 매니페스트 | 작성 확인: `docker-compose.app.yml`, `docker-compose.core.yml`, `docker-compose.ops.yml`. 실제 배포 여부는 미실시 |

## 2. 감지 지표 및 계획 기준

아래 기준은 기획서에 명시된 **계획값**이며 운영 측정 결과가 아니다. 기획서는 API·DB·LLM 비율 기반 경보의 상세 임계값을 정하지 않으므로 정책 정본 확정이 필요하다.

| 유형 | 감지 지표·계획 기준 | 실제 결과 |
|---|---|---|
| 네트워크 / backend | Gateway `/ready` 2초 간격 확인, 2회 연속 실패 시 stack 제외, 2회 연속 정상 시 재등록 | ________ |
| API 오류 | 실제 interpreter 요청 HTTP 5xx 및 연속 실패·회로 상태 기록. Monitor는 5초 간격 평가, 2회 연속 실패를 판정 기준으로 계획 | ________ |
| API 지연 | 요청별 경과시간 기록. 5초 초과를 장애로 감지하고 전환·재시도 총 상한 15초 | ________ |
| LLM / interpreter | interpreter별 실제 요청 성공·실패, 연속 실패 및 회로 상태 기록. 3회 연속 transport 실패 후 60초 차단, 이후 단일 probe | ________ |
| 프롬프트 / 에이전트 출력 | 출력 계약 validator 오류와 재생성 횟수 기록. 최초 생성 포함 총 3회까지, 소진 시 `NEEDS_REVIEW` | ________ |
| DB / 메뉴 조회 | 단건 메뉴 조회 실패와 전체 DB 연결 장애를 구분. 캐시 브랜드·버전·checksum 및 세션 pin 검증 | ________ |
| 공통 성능 지표 | 목표 MTTD ≤15초. 목표 MTTR: F-1·F-2·F-5·F-6 ≤60초, F-3 ≤90초 | MTTD: ________; MTTR: ________ |

## 3. 장애 유형별 복구 계획 및 시험 결과

| 유형 | 계획된 자동 복구 및 독립 검증 | 상태 / 결과 |
|---|---|---|
| F-1 HTTP 5xx | 회로 상태 확인 후 반대 interpreter로 최대 1회 전환. 별도 기능 요청과 결과 계약 검증 | 미검증 / ________ |
| F-2 5초 초과 지연 | F-1과 같은 전환, 전체 처리 15초 상한. 정상 응답과 결과 계약 검증 | 미검증 / ________ |
| F-3 backend 중단 | 비정상 stack 제외, healthy한 B로 전환. 허용목록 backend 재시작 후 `/health`, `/ready`, frontend 연결 및 기능 검증 | 미검증 / ________ |
| F-4 반복 장애 | interpreter별 3회 연속 실패 시 60초 차단 후 단일 probe. probe 실패 시 승인 대기 상태로 두고 자동 반복 금지 | 미검증 / ________ |
| F-5 잘못된 에이전트 출력 | 검증 오류를 재생성 입력에 반영하고 최대 2회 재생성. 실패 시 `NEEDS_REVIEW`, 자동 완료·공유 차단 | 미검증 / ________ |
| F-6 메뉴 조회 실패 | 동일 브랜드·버전·checksum의 stale cache만 폴백하고 세션 버전 고정. 안전한 캐시가 없으면 실패/검토 처리 | 미검증 / ________ |

### 무개입 복구 비율

**산식:** 수동 개입 없이 독립 검증까지 통과한 유효 시험 회차 ÷ 전체 유효 시험 회차 × 100 = ________%

사전 준비 실패 또는 증거가 남은 주입 도구 오류만 유효 분모에서 제외한다. 사람 개입, `AWAITING_APPROVAL`, 검증 실패 회차는 성공 분자에서 제외하며, 사람 개입 회차는 유효 분모에 포함한다. 기획된 정식 측정은 F-1·F-2·F-3·F-5·F-6 각 5회(총 25회)이며 F-4 안전성 시험은 별도 집계한다. 현재 시험 미실시로 비율은 산출하지 않았다.
